# Yeisme Indagator CLI Runtime

Use this skill for `agent/indagator`, the crawler orchestration and parser/manifest/download control-plane CLI.

## Boundary

- CLI entrypoint: `agent/indagator/cmd/indagator`.
- Cobra command tree and runtime wiring live in `internal/cli` and `internal/cli/commands`.
- Viper typed config lives in `internal/config`.
- Output rendering lives in `internal/cli/render` and must follow `ai-native-cli-output-contract`.
- Connect RPC clients live in `internal/client`; CLI should call clients or explicit test fixtures, not service implementations.
- Generated command reference pages live in `docs/commands/**` and are maintained only by `scripts/generate-command-docs.py`.

## Command Docs Workflow

1. Edit Cobra source first: `Use`, `Short`, `Long`, examples, flags, and command registration in `internal/cli/**` or `cmd/indagator/commands.go`.
2. Regenerate generated docs from Cobra help:

```bash
cd agent/indagator
python3 scripts/generate-command-docs.py
```

3. Check freshness:

```bash
cd agent/indagator
python3 scripts/generate-command-docs.py --check
```

4. Do not hand-edit files containing:

```text
<!-- GENERATED by scripts/generate-command-docs.py; do not edit by hand. -->
```

5. Update non-generated operator docs only when workflow semantics changed: `docs/README.md`, `docs/cli-operator-guide.md`, or runtime design docs.

## CLI Rules

- Default output is human summary; `--json`, `--agent`, `--events`, and `--explain` come from one projection.
- Machine stdout must be format-pure; diagnostics go to stderr or redacted evidence.
- `--events` is only for streaming commands such as `downloads watch`.
- Config precedence is flags > env > config file > defaults, with tests able to inject higher-priority values.
- Secret refs, tokens, cookies, Authorization headers, raw provider payloads, hidden prompts, and chain-of-thought must never appear in docs, output, traces, fixtures, or evidence.
- CLI remains thin: no direct imports of fetcher, parser adapter, downloader adapter, rpcserver, browser bridge, summarizer, reporter, bundler, Firecrawl, or other service implementations.

## Validation

For command docs only:

```bash
cd agent/indagator
go test ./internal/docs -run TestGeneratedCommandDocsAreCurrent -count=1
```

For command/config/output changes:

```bash
cd agent/indagator
go test ./cmd/indagator ./internal/cli/... ./internal/config ./internal/docs
```

Before completion after code or command behavior changes:

```bash
cd agent/indagator
go test ./...
task build
openspec validate --all --strict
```

If integration behavior changes, also run:

```bash
cd agent/indagator
task test:integration
```
