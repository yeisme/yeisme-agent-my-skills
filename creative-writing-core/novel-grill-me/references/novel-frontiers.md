# 小说 Frontier 地图

按当前 artifact 只选择一个分支；下游答案改变读者、篇幅、媒介、原创性或 canon 时重新打开受影响分支。

## Project / Reader Contract

- 目标读者、阅读场景、类型承诺和核心情绪回报。
- 短篇、中篇、长篇、系列或连载；完结优先还是持续扩展。
- 每章/每卷稳定兑现什么，明确不写什么。
- 原创、授权改编、研究性参考和相似性边界。
- 完成标准：样章、首卷、全书大纲、完整正文或运营试验。

## Premise / World / Character

- 主角追求、主动选择、失败代价、内外冲突和不可逆后果。
- 世界规则如何制造限制、机会和不对称，而不只是设定展示。
- 反作用力、关系张力、秘密、知识边界和人物改变方向。
- 主题通过哪些选择和后果被证明。

## Length / Volume / Serial Engine

- 分卷功能、阶段目标、升级曲线、伏笔回收窗口和终局承诺。
- 章节状态变化、信息增量、人物推进和章尾承诺。
- 更新频率、库存与反馈可以影响哪些未来分支。
- 可扩写结构与灌水的停止线。

## POV / Voice / Scene

- 视角、人称、时态、叙述距离、信息限制和切换规则。
- 叙述声音、人物对白、禁写和保留项。
- 场景目标、阻力、转折、后果、感官锚点和对话功能。
- 说明性信息由冲突、行动、观察还是叙述承担。

“文风是否有辨识度、人物是否鲜活、章节是否让人追读”属于 hypothesis，转为短试写、双候选或读者测试。

## Revision / Review / Adaptation

- 当前缺陷是结构、人物、连续性、节奏、对白、叙述自然度还是平台适配。
- 哪些正文和设定已 accepted，哪些只是 candidate。
- 反馈来源、证据强度、可归因缺陷和单轮修订边界。
- 改编不可牺牲承诺、删改边界、目标媒介结构和 rights gate。
