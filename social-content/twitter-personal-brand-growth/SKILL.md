# Twitter/X 个人品牌增长策划

基于个人品牌四步法，帮助创作者、研究者、创始人和内容团队设计 Twitter/X 起号、矩阵号、内容系统和商业化路径。这里的 `X` 明确指原 Twitter 平台，不指小红书、未知变量或泛社交平台。输出以可执行计划、选题矩阵、推文/长线程 brief 和 Auctra 可接收素材为主，不承诺涨粉结果。

## 输入

- Twitter/X 账号定位、目标读者、领域、语言、当前粉丝数、过往推文/线程和目标动作。
- 账号矩阵角色、主号/子号边界、Newsletter、产品、咨询或社群路径。
- 可用素材源、更新频率、团队分工、时间预算、禁区和平台风险。

## 输出

- 个人品牌定位：用户需求、兴趣、擅长能力的交叉点，以及空间/内容/时间一致性建议。
- 内容系统：选题框架、标签、输入源、扫描规则、素材笔记、主题/标题/大纲和推文产出节奏。
- 增长系统：内容数、曝光量、粉丝/订阅转化率的拆解动作。
- 矩阵起号方案：主号、垂直号、案例号、分发号的角色、内容边界、交叉链接和复用规则。
- 商业化路径：咨询、付费订阅、社群、课程/出版物、广告、投资或产品化的先后顺序和验证门槛。

## 参考资料

只在任务需要 Twitter/X（原 Twitter）起号、个人品牌增长或矩阵号细则时读取：

## 工作流

1. 先确认目标是个人品牌、单号增长、账号矩阵、Newsletter 转化还是商业化验证。
   - 用户说 `X`、`推特`、`Twitter`、`X 账号`、`X 矩阵` 时，默认都按 Twitter/X 平台处理。
   - 只有用户明确说 `小红书`、`RedNote`、`XHS` 或 `小红书个人品牌` 时，才路由到小红书技能。
2. 用“用户需求 x 兴趣 x 擅长”收敛定位；定位不清时先输出候选定位和验证问题。
3. 建立内容系统：从定位拆标签和输入源，再给扫描、精读、素材、主题、文章/线程的流水线。
4. 建立增长系统：用“内容数 x 曝光量 x 转化率”拆动作，区分有机增长、交叉链接、渠道分销和付费增长。
5. 需要矩阵起号时，明确每个账号的角色、不可重复的用户承诺、复用素材边界和互相导流方式。
6. 最后给出 2-4 周可执行节奏、衡量指标、风险检查和 Auctra 项目接入建议。

## 质量门槛

- 每个建议必须落到具体账号角色、选题、频率、分发或转化动作。
- 不把“多发内容”当作完整策略；必须同时覆盖定位、一致性、内容系统、增长系统和商业化验证。
- 矩阵号必须共享素材和证据系统，但面向不同用户承诺；不要制造多个同质账号。
- 缺少真实经历、案例、能力证明或素材源时，列为输入缺口，不替用户编造。

## Auctra 轻集成

- 可将账号定位和选题矩阵转成 Auctra brief 或 material，再生成推文线程、Newsletter、公众号或小红书改写稿。
- 可建议真实命令，例如 `auctra text new twitter_thread --title "个人品牌四步法" --platform twitter --json`，但不手写 `.auctra/**` 状态。
- 需要多平台复用时，先输出源内容 brief，再路由给小红书、公众号、短视频或播客技能改写。

## 边界

- 不执行登录、发帖、私信、自动关注、刷量、爬取隐私数据、规避平台风控或购买虚假互动。
- 不承诺涨粉、成交、平台推荐、投资回报或病毒传播。
- 不伪造用户经历、数据、背书、截图、收入、客户案例或平台反馈。
- 不把完整思维链、原始提示词、供应商载荷、隐藏系统提示或私密工具参数写入稿件、证据、日志或结构化资产。

## 验证

- 检查输出是否覆盖定位、内容系统、增长系统、转化/商业化、指标和风险。
- 检查每个账号或内容栏目是否有清晰用户承诺和可持续素材来源。
- 若用于 Auctra，确认结构化变更必须通过 Auctra CLI 或应用服务完成。
