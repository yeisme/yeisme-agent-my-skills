# Creative Writing Core Skills

跨小说、短剧和内容创作的最小路由层，提供创作入口、风格 Lens、渐进式编排、决策访谈和按需安装协议。它只选择或约束后续 Skill，不成为新的正文或项目正典 Owner。

## 创作决策访谈

- `creative-grill-me`：聚合入口，路由小说、漫剧、其他 AI 做剧、改编和通用内容。
- `novel-grill-me`：小说立项、结构、人物、章节、修订、连载与改编直达入口。
- `manga-drama-grill-me`：漫剧故事、分镜、视觉、声音、生产和交付直达入口。
- `creative-grilling`：共享 Frontier、深度选择和 `v0.1` route/brief/handoff 合同。

三个公开入口均为显式调用。访谈只读，确认后才串行交给 Auctra 或 Scaena owner handoff；领域 router 和 canonical owner 继续负责持久化、review 与生产。
