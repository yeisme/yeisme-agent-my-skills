# 中文小说全媒介改编矩阵

## 使用时机

当用户要把小说改成短剧、长电视剧、电影、广播剧、有声书、漫画/动态漫、游戏剧情或短视频系列时读取本文件。先做改编架构和交接包，再交给具体脚本或内容技能写成品。

## 改编原则

- 保留原作核心承诺，不逐章搬运。
- 内心戏要外化成行动、对白、声音、画面、选择或任务。
- 媒介节奏优先于原章节顺序；必要时前置名场面、合并角色、重排事件。
- 每个交接包都写清保留内容、可删改内容和制作限制。

## 媒介矩阵

| 媒介 | 结构单位 | 强项 | 主要改写动作 | 交接对象 |
| --- | --- | --- | --- | --- |
| 短剧 | 集 / 场 / 钩子 | 高频反转、强情绪、强冲突 | 前置冲突、压缩铺垫、集尾钩子 | screenplay / short-video |
| 长电视剧 | 季 / 集 / A-B 线 | 人物关系、群像、长线悬念 | 分季问题、角色线并行、集尾推进 | screenplay |
| 电影 | 三幕 / 序列 / 场 | 高概念、视觉高潮、集中情绪 | 合并支线、压缩人物、强化主选择 | screenplay |
| 广播剧 | 集 / 声音场景 | 声音线索、对白、氛围 | 声音化动作、减少视觉依赖 | podcast / screenplay |
| 有声书 | 章节 / 演播提示 | 保留文本、声音表演 | 标注角色声线、节奏和停顿 | podcast |
| 漫画/动态漫 | 话 / 页 / 格 | 视觉钩子、表情、动作 | 页钩子、画面转折、减少旁白 | screenplay / visual direction |
| 游戏剧情 | 任务 / 选择 / 分支 | 参与感、选择代价、探索 | 任务化目标、分支后果、NPC 弧线 | narrative handoff |
| 短视频系列 | 条 / 口播 / 分镜 | 快速传播、观点提炼 | 提炼名场面、主题钩子、系列标题 | short-video |

## 短剧改编包

```markdown
- 目标集数与单集时长：
- 前 3 集钩子：
- 每集结构：开场冲突 / 中段反转 / 结尾钩子
- 角色合并：
- 场景控制：主场景、可复用场景、昂贵场景
- 每集表：集号 / 核心事件 / 情绪爆点 / 反转 / 钩子
```

## 长电视剧改编包

```markdown
- 季核心问题：
- A 线：主线事件推进
- B 线：人物关系或职业线
- C 线：反派/秘密/世界规则
- 分集表：集号 / A 线推进 / B 线变化 / 新信息 / 集尾问题
- 季末兑现与下一季引线：
```

## 电影改编包

```markdown
- 一句话高概念：
- 第一幕：日常秩序、触发事件、不可回头选择
- 第二幕：追求目标、错误胜利、中点反转、低谷
- 第三幕：最终选择、高潮、结局余味
- 必须合并或删除的支线：
- 视觉高潮：
```

## 广播剧/有声书改编包

```markdown
- 声音卖点：环境声 / 道具声 / 角色声线 / 沉默
- 旁白策略：保留 / 压缩 / 改成对白 / 改成声音动作
- 每集声音钩子：
- 角色声线表：
- 演播风险：同质化对白、说明过多、动作不可听
```

## 漫画/动态漫改编包

```markdown
- 视觉卖点：人物造型 / 场景奇观 / 动作 / 表情 / 道具
- 分话结构：开页钩子 / 中段翻页点 / 话尾钩子
- 页钩子：每 3-5 页一个信息或情绪变化
- 旁白压缩：哪些内心改成画面
- 角色/场景设计需求：
```

## 游戏剧情改编包

```markdown
- 玩家身份：
- 主任务目标：
- 支线任务：人物关系 / 世界规则 / 资源代价
- 选择点：选择 A / 选择 B / 后果
- NPC 弧线：
- 不适合游戏化的原作内容：
```

## 交接检查

- 是否列出不可牺牲内容。
- 是否说明删改、合并、前置和外化策略。
- 是否有明确结构单位：集、幕、话、任务或条。
- 是否指向下一步具体技能，而不是停在抽象建议。
