# Eikona 小红书漫画图文导演

把观点、教程或故事设计成小红书可读的静态漫画风格图文。

## 输入

- 主题、角色、场景、剧情节点、目标读者、画风和页数。
- 可选：品牌色、角色禁忌、是否需要对白气泡。

## 工作流

1. 拆出漫画页序：冲突、误区、发现、解决、总结或互动。
2. 为每页写画面描述、角色动作、对白气泡和旁白。
3. 统一角色设定和画风，避免每页角色长相漂移。
4. 输出 Eikona dry-run 命令和逐页提示词。

## 命令示例

```bash
eikona generate --model openai:gpt-image-2 --aspect 3:4 --size 1024x1536 --count 4 --prompt "小红书漫画风格图文，四页，主题是新手护肤误区，统一角色，柔和配色，中文对白气泡清晰，轻松真实" --dry-run --json
```

## 质量标准

- 漫画要服务信息表达，不只追求可爱。
- 不使用侵犯真人肖像、商标或受版权保护角色的设定。
- 复杂医学、金融、法律建议必须保守表达并提示核实。
