# 中文小说关系场景库

## 使用时机

当章节需要初遇、试探、关系冲突、误会、告白、背叛、和解或情绪回报时读取。关系场景必须改变双方的信任、筹码、亏欠、吸引、怨恨或边界，不能只写漂亮对白。

## 场景模板

```markdown
## 关系场景卡
- 场景类型：初遇 / 试探 / 冲突 / 误会 / 告白 / 背叛 / 和解
- 角色A表层目标：
- 角色A隐藏需求或恐惧：
- 角色B表层目标：
- 角色B隐藏需求或恐惧：
- 关系筹码：秘密 / 亏欠 / 利益 / 保护 / 欲望 / 愧疚
- 不能说出口的话：
- 权力变化：谁从弱势变强，或谁暴露软肋
- 离场关系状态：更近 / 更远 / 假性和解 / 暂时结盟 / 决裂
```

## 预设场景

### 初遇

- 入场：双方对彼此有错误预设。
- 压力：他们必须合作、竞争或互相评估。
- 关键动作：一个人看见另一个人的真实能力或隐藏弱点。
- 转折：第一印象被打破，但新的误解产生。
- 离场：关系不是“喜欢/讨厌”，而是多一个未解决问题。

### 试探

- 入场：一方想确认对方立场，但不愿暴露真实目的。
- 压力：问得太直接会失去筹码。
- 关键动作：用玩笑、反问、假情报或小请求测试边界。
- 转折：对方看穿试探，反过来设局。
- 离场：双方都得到一点信息，也都更警惕。

### 误会

- 入场：双方掌握的信息不对等。
- 压力：解释会暴露更大秘密，不解释会伤害关系。
- 关键动作：角色选择沉默、转移话题或说半真话。
- 转折：误会带来实际后果，而不是拖剧情的借口。
- 离场：关系出现裂痕，同时给未来澄清留下证据。

### 告白

- 入场：告白不是目的本身，而是某个压力下的选择。
- 压力：时间、危险、竞争者、误解或即将分别。
- 关键动作：角色说出的不是完美情话，而是承担代价的承诺。
- 转折：回应不一定是接受，也可以是提出条件或更深冲突。
- 离场：关系进入新规则。

### 背叛

- 入场：读者以为某段关系稳定。
- 压力：背叛者面对更高代价或更强诱因。
- 关键动作：背叛必须有前文 seed：恐惧、亏欠、利益、误判或保护。
- 转折：背叛行为同时暴露真实软肋。
- 离场：受害方失去资源或信任，背叛方得到代价。

### 和解

- 入场：双方都有理由不低头。
- 压力：外部事件迫使他们重新面对旧伤。
- 关键动作：不是解释误会，而是有人承担具体后果。
- 转折：和解解决一个旧问题，但打开新的边界。
- 离场：关系改变可见行动，而不只是口头原谅。

## 检查表

- 对白是否包含潜台词，而不是直接说出心理分析。
- 关系变化是否能用一个具体行动证明。
- 误会是否由人物缺陷和信息边界造成，而不是作者强行不解释。
- 情绪回报是否绑定代价。
- 本场是否更新 `character_state` 和 `knowledge_boundary`。
