# 中文小说升级与对抗场景库

## 使用时机

当章节需要升级、战斗、竞赛、谈判、资源争夺、失败代价或阶段性胜利时读取。升级场景的重点不是数值变大，而是选择更难、代价更具体、读者回报更清楚。

## 场景模板

```markdown
## 升级场景卡
- 场景类型：升级 / 战斗 / 竞赛 / 谈判 / 资源争夺 / 失败代价
- 当前目标：
- 对手或阻力：人物 / 组织 / 环境 / 规则 / 时间
- 资源：能力、盟友、道具、情报、体力、声望
- 限制：不能使用什么，使用会付出什么
- 策略：正面压制 / 诱导 / 交换 / 绕路 / 冒险 / 牺牲
- 中段反制：对手如何打破主角预案
- 结果：胜利 / 惨胜 / 失败 / 假胜利 / 换取下一次机会
- 失败代价：身体、关系、资源、秘密、声望、时间
```

## 预设场景

### 升级

- 入场：主角旧方法失效。
- 压力：不升级会失去重要目标。
- 关键动作：主角尝试新能力、新策略或新认知。
- 转折：升级成功但暴露副作用或新敌人。
- 离场：能力上限变高，风险也变高。

### 战斗

- 入场：双方目标不只是打败对方，还要争夺具体结果。
- 压力：环境、旁观者、时间限制或伤病影响打法。
- 关键动作：每一轮交锋都改变位置、资源或心理。
- 转折：对手识破主角惯用策略。
- 离场：胜负带来后果，不用无代价升级收尾。

### 竞赛

- 入场：规则公开，但每个人掌握的资源不同。
- 压力：主角不能只赢，还要保住身份、关系或秘密。
- 关键动作：主角利用规则边界，而不是凭空开挂。
- 转折：规则被重新解释或有人违规。
- 离场：排名、声望、敌意或新机会改变。

### 谈判

- 入场：双方都不能直接夺取目标，只能交换。
- 压力：筹码不对等或时间不站在主角这边。
- 关键动作：主角隐藏真实底线，抛出可牺牲筹码。
- 转折：对手提出会伤害主角关系或原则的条件。
- 离场：达成协议、破局失败或埋下背叛。

### 资源争夺

- 入场：资源有限且有明确归属争议。
- 压力：拿不到资源会影响下一章行动。
- 关键动作：主角选择抢、骗、换、借、放弃或毁掉资源。
- 转折：资源本身带有副作用或隐藏条件。
- 离场：资源状态进入 continuity ledger。

### 失败代价

- 入场：主角认为自己可以承受风险。
- 压力：失败不是抽象挫折，而是具体损失。
- 关键动作：错误判断导致损失发生。
- 转折：主角发现真正代价落在别人身上。
- 离场：人物缺陷被迫面对，下一步策略改变。

## 检查表

- 升级是否绑定限制和副作用。
- 胜利是否有代价，失败是否推进人物或情节。
- 对手是否主动反制，而不是等待主角表演。
- 资源状态是否可追踪。
- 本场读者回报是否清楚：爽点、策略、代价或新机会。
