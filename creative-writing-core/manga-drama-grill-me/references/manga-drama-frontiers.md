# 漫剧 Frontier 地图

按当前 phase 选择最小分支，不把完整生产链一次展开。

## Intake / Format

- 目标观众、观看场景和一次消费承诺。
- 漫剧形态、画幅、单集时长、集数、连载/完结和 proof slice。
- 类型引擎、每集重复承诺、明确不支持的内容。
- 原创、授权改编或受约束参考；权利不明时阻断生产。

## Story / Character / Series

- premise、戏剧问题、主题命题和观众期待的 payoff。
- 主角欲望、主动选择、代价、失败后果和反作用力。
- 人物关系如何产生可重复冲突。
- 单集闭环与长期累积的比例、升级规则和终局方向。
- 哪些 canon 可以改变，哪些接受后必须稳定。

## Episode / Scene

- entry state、目标、阻力、转折和 exit state。
- 信息由动作、画面、对白还是声音承担。
- 开场压力、节奏变化、话尾/集尾钩子和下一步承诺。
- 人物知识边界、因果连续性和不可交换的人物声音。

## Storyboard / Visual / Audio

- 情绪目标、表演、调度、空间、景别、角度、运镜和剪辑节奏。
- 主体、服装、道具、背景连续性和可复用资产。
- 对白密度、字幕负担、环境声、Foley、音乐和静音意图。
- 参考是高层原则、流派约束还是受保护表达。

## Production / Review / Delivery

- canonical owner、candidate/selected/accepted 状态和人工确认点。
- 预算、时限、capability、批次、失败重试和 kill switch。
- 谁能暂停、接管、终止和批准 plan digest。
- rights、continuity、cost、audio、similarity 和 delivery gate。
- 从 proof slice 扩展到 bounded batch 所需证据。
