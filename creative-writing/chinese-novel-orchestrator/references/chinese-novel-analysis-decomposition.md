# 中文小说分析拆解模板

## 使用时机

当用户要求“分析这部小说”“拆主题”“拆结构”“拆人物弧线”“复盘为什么好看/不好看”“提炼可改编价值”时读取本文件。拆解必须服务下一步创作、修订、改编或内容转化。

## 拆解总表

```markdown
- 文本范围：全文 / 前 N 章 / 梗概 / 单章 / 片段
- 拆解目标：主题 / 结构 / 人物 / 场景 / 伏笔 / 改编 / 修订
- 已知事实：
- 分析判断：
- 可执行建议：
- 下一步 handoff：
```

## 主题拆解

```markdown
- 表层题材：
- 核心命题：作品真正反复证明的问题
- 反命题：反派、环境或旧秩序相信什么
- 人物承载：谁用行动证明主题
- 场景证明：哪些场景让主题变成可见选择
- 结局回答：结尾如何回答核心命题
- 风险：主题只停留在口号 / 人物行为没有证明主题
```

## 人物弧线拆解

## 伏笔与回收拆解

```markdown
- seed：
- 表层解释：

- 升级节点：

- 是否公平：读者能否回看发现证据

```

## IP 可改编性评估

| 维度 | 问题 | 评分 |
| --- | --- | --- |
| 核心卖点 | 一句话是否能说清观众入口 | 高/中/低 |
| 可视化场景 | 是否有可拍、可画、可听的名场面 | 高/中/低 |
| 人物关系 | 是否有持续拉扯和冲突 | 高/中/低 |
| 结构弹性 | 是否能拆成集、幕、话或任务 | 高/中/低 |
| 成本风险 | 是否依赖大量昂贵场景或特效 | 高/中/低 |
| 改编风险 | 内心戏、旁白、世界观解释是否过重 | 高/中/低 |

## 输出检查

- 每个判断是否有文本证据或用户材料支撑。
- 是否区分事实、推断、建议。
- 是否给出下一步：修订、扩写、压缩、改编或平台化拆分。
