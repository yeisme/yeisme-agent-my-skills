# 中文小说主题拆分模板

## 使用时机

当用户需要“拆主题”“把小说主题拆成选题/章节/场景/改编角度”“提炼作品想表达什么”时读取本文件。主题必须落到人物选择、场景证明和读者情绪回报。

## 主题不是口号

不要只写成长、救赎、复仇、女性力量、命运、自由。主题应写成可被剧情证明的命题，例如：“真正的复仇不是让敌人痛苦，而是夺回定义自己的权力。”

## 主题到场景

```markdown
- 场景 1：让主角旧信念看似有效
- 场景 2：旧信念制造代价
- 场景 3：反命题提出诱惑
- 场景 4：主角做出新选择
- 场景 5：结局证明新选择的代价和价值
```

## 主题到平台表达

```markdown
- 小说正文：用行动和后果呈现，不直接说教
- 书评/拆解：提炼命题和证据
- 小红书/短视频：拆成一个情绪入口、一个名场面、一个个人化问题
- 改编剧本：把主题改成可见选择、对白潜台词和结尾画面
```

## 风险检查

- 主题是否只是抽象词，没有命题。
- 人物是否只说主题，没有用行动承担代价。
- 结局是否回答了开篇提出的问题。
- 平台化表达是否歪曲原作事实或伪造作者意图。


## 主题到结构

```markdown
- 开篇：让读者看见旧秩序为什么压迫主角
- 第一转折：主角用旧信念行动，并获得短暂好处
- 中段：旧信念制造更大代价，反命题变得有诱惑力
- 低谷：主角必须承认旧信念无法解决问题
- 高潮：主角用新选择承担代价
- 结尾：世界是否被改变，主角是否被改变
```

## 主题到改编

```markdown
- 短剧：把主题压成高频选择和情绪反转，不用大段主题对白
- 长电视剧：让不同角色分别承载主题的不同答案
- 电影：集中到一个最终选择和一个视觉化结尾
- 广播剧/有声书：用声音线索、沉默和对白潜台词承载主题
- 漫画/动态漫：用构图、表情、道具和页钩子反复证明主题
- 游戏剧情：把主题变成玩家选择、任务代价和 NPC 反馈
```

## 检查清单

- 主题是否能写成一句可争辩命题。
- 反命题是否有足够诱惑力，而不是纸片反派观点。
- 主角是否用行动证明主题，而不是用独白解释主题。
- 配角是否提供不同答案，避免所有角色替作者说同一句话。
- 主题拆成平台内容时是否保留事实边界，不伪造作者意图。
- 主题改编成剧本时是否变成可见选择、可听对白或可拍画面。
