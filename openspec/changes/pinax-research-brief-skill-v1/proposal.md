# 研究简报工作流固化

## Why

五题已获批次认可，用户批准的回顾性检索 5/5、引用与采纳后保存通过。需要将操作步骤固化，避免自动存档、无界检索及把历史来源当成当前事实。首轮找回率仍未测量。

## What Changes

更新既有公共 Pinax 操作 Skill，复用 CLI 检索、读取和保存。无新增产品命令、公共 API、schema 或后台。

## Capabilities

### New Capabilities
- `research-brief-workflow`: 当前 Agent 的有界研究简报操作指导。

### Modified Capabilities
无。

## Impact

归属 split-owner：Pinax 拥有命令及使用文档，公共 Skill source 拥有 Agent 路由；模板规范保持固定引用。前置证据在 Pinax `pinax-evidence-research-pilot-v1/acceptance.md`。只做本地固化，不发布或替换用户 CLI。
