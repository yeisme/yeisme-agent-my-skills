# 中文小说过渡与缓冲场景库

## 使用时机

当章节需要过渡章、日常缓冲、旅途、训练、调查间隙或余波时读取。过渡场景不是“没事发生”，而是用低强度场景完成关系、信息、状态和节奏的换挡。

## 场景模板

```markdown
## 过渡场景卡
- 场景类型：过渡章 / 日常缓冲 / 旅途 / 训练 / 调查间隙 / 余波
- 上一段高压事件留下的问题：
- 本场要恢复或改变的状态：身体 / 情绪 / 关系 / 资源 / 线索 / 计划
- 低强度冲突：尴尬、疲惫、隐瞒、资源不足、路线选择、训练瓶颈
- 暗线推进：伏笔、关系、世界规则、敌人动作、下一目标
- 离场：角色能进入下一段高压剧情的理由
```

## 预设场景

### 过渡章

- 入场：上一章高潮结束，角色暂时脱离直接危险。
- 压力：读者需要喘息，但故事不能停。
- 关键动作：处理后果、分配任务、确认下一目标。
- 转折：一个小信息说明危机并未结束。
- 离场：角色有明确下一站或下一步。

### 日常缓冲

- 入场：角色回到吃饭、睡觉、整理、闲聊等低压环境。
- 压力：日常里藏着未解决情绪或关系裂缝。
- 关键动作：用小动作展示人物变化。
- 转折：轻松表层下出现异常细节或未说出口的话。
- 离场：读者获得情绪回报，同时被引向新问题。

### 旅途

- 入场：角色从一个地点前往另一个地点。
- 压力：路途有时间、环境、追踪、费用或同伴冲突。
- 关键动作：旅途中完成信息交换、关系变化或世界规则展示。
- 转折：目的地信息变化，或路上出现意外阻力。
- 离场：到达时状态已不同。

### 训练

- 入场：角色知道旧能力不够。
- 压力：训练有期限、瓶颈、师徒冲突或身体代价。
- 关键动作：失败比成功更重要，暴露缺陷。
- 转折：角色找到方法，但代价改变下一场策略。
- 离场：能力进步可见，限制也更清楚。

### 调查间隙

- 入场：主角等待结果、整理线索或走访边缘人物。
- 压力：时间流逝，错误方向会消耗机会。
- 关键动作：边缘信息改变一个小判断。
- 转折：间隙不是空白，而是敌人也在行动。
- 离场：下一次调查更有方向或更危险。

### 余波

- 入场：冲突已经结束，但后果开始显形。
- 压力：胜利或失败都要结算。
- 关键动作：角色面对损失、愧疚、奖励、惩罚或新身份。
- 转折：余波中的一个细节暗示更大问题。
- 离场：读者感到上一段剧情被认真对待。

## 检查表

- 过渡是否改变状态，而不是拖字数。
- 日常是否服务人物、关系或伏笔。
- 旅途是否有路途限制和信息变化。
- 训练是否有失败、瓶颈和代价。
- 余波是否结算上一段剧情的后果。
