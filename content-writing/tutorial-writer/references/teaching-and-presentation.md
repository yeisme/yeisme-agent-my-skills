# 教学与演讲参考

这份普通 reference 同时服务课件、PPT 讲稿和长期讲课视频。它只提供内容组织方法，不新增内容类型、CLI、存储表或渲染器。

## 共同骨架

1. **目标与起点**：说明读者已有知识、完成后能做什么，以及不覆盖什么。
2. **学习顺序**：从必要前置到核心概念，再到示范、练习和复盘；每一步说明为什么现在学习它。
3. **例子与讲义**：例子必须服务当前目标，区分事实、假设和演示数据；没有来源的信息列为待补，不擅自补齐。
4. **步骤与检查点**：关键步骤给出可操作动作、预期结果和失败时的排查方向。
5. **练习与答案**：练习检验本节目标，答案解释判断过程和常见误区，不只给结论。
6. **收束与下一步**：总结可迁移方法、复习问题和下一次学习的前置条件。

## PPT 讲稿

按页组织：页标题 → 页面要点 → 口头讲稿 → 与上一页/下一页的衔接 → 预计时长 → 演示或提问动作。讲稿补充页面不能承载的解释，但不凭空增加页面，也不把页面要点改写成小说式冲突。

建议为每页标注：

- 本页唯一目的和听众应记住的一句话；
- 讲解、演示、提问或停顿的类型；
- 所需素材、事实来源和缺口；
- 预计时长及超时时可删的旁枝。

## 课程系列与长期讲课视频

按课程、课次和单节目标组织。每课次写明先修知识、口播结构、演示步骤、预计时长、复习和练习；跨课次保留术语、能力递进和复习入口。长视频可以设置章节和回顾点，但不套短视频强钩子、连续反转或追热点模板。

每次交付前检查：目标是否可验证、顺序是否跳步、示例是否真实可解释、讲义与口播是否一致、练习是否覆盖目标、答案是否能帮助自检、时长是否可执行。

## 边界

`tutorial-writer` 负责教学内容；`natural-writing-editor` 只在用户要求修订或终稿自然度复检时作为约束或 revise owner。普通稿件仍可使用现有 `manuscript`、`speech`、`long_video_script` 等类型，不发明新的模型或目录。
