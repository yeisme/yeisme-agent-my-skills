# 中文小说悬疑场景库

## 使用时机

当章节需要线索发现、误导、审讯、跟踪、追查、反转、真相推进或案件压力时读取。悬疑场景的核心不是“藏答案”，而是公平地控制读者、主角、嫌疑人之间的信息差。

## 场景模板

```markdown
## 悬疑场景卡
- 场景类型：线索发现 / 误导 / 审讯 / 跟踪 / 现场复盘 / 真相推进
- 表层问题：角色正在调查什么
- 隐藏问题：真正重要但暂时不能明说的是什么
- 线索载体：物品 / 话语 / 行为 / 时间差 / 空间异常 / 规则漏洞
- 误导方向：读者或主角会先误以为什么
- 公平证据：回看时能证明真相的细节
- 阻力：嫌疑人、制度、时间、情绪、错误常识、证据污染
- 本场结论：答案 / 新问题 / 错误结论 / 更大风险
- payoff 计划：何时回收，如何回看合理
```

## 预设场景

### 线索发现

- 入场：主角带着旧判断进入现场。
- 压力：现场即将被清理、证人要离开、上级催结案。
- 关键动作：主角注意到一个“不该存在”或“本该存在却消失”的细节。
- 转折：线索不直接指向真凶，只推翻一个前提。
- 离场：主角得到新问题，嫌疑范围扩大或缩小。

### 误导

- 入场：证据看似指向最明显的人。
- 压力：读者和配角都倾向接受简单答案。
- 关键动作：主角被迫按错误方向行动，付出时间或关系代价。
- 转折：一个小细节让误导出现裂缝，但暂时无法证明。
- 离场：错误答案仍有诱惑，真相 seed 已埋下。

### 审讯

- 入场：双方都知道这不是普通问答，而是筹码交换。
- 压力：嫌疑人有时间优势、身份保护或情绪操控能力。
- 关键动作：主角不问真问题，先用假前提试探对方反应。
- 转折：嫌疑人回避的不是罪行，而是另一个更危险秘密。
- 离场：得到半真半假的信息，留下后续验证任务。

### 跟踪

- 入场：主角必须保持距离，同时不能失去目标。
- 压力：环境复杂、目标警觉、同伴拖慢、时间窗口短。
- 关键动作：目标做出不符合身份的选择。
- 转折：主角发现自己也在被观察。
- 离场：从追踪者变成被追踪者，危险升级。

### 真相推进

- 入场：已有多个碎片，但解释互相冲突。
- 压力：错误解释会导致无辜者受害或真凶逃脱。
- 关键动作：主角把两个看似无关的细节并置。
- 转折：真相不是新增线索，而是旧线索换了含义。
- 离场：读者获得“原来如此”的阶段回报，同时打开最终问题。

## 检查表

- 线索是否有载体，而不是作者直接告诉读者。
- 误导是否公平，不能靠隐藏关键事实欺骗读者。
- 真相推进是否改变行动策略。
- 嫌疑人的沉默、谎言和情绪是否各有目的。
- 本场是否留下可追踪的 `foreshadowing` 或 `continuity_delta`。
