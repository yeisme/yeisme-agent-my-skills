# 小说到剧本转译规则

当用户给的是小说段落、散文式梗概、人物内心或作者讲述，而目标是电影、短剧、舞台剧、广播剧或场景剧本时读取本文件。核心原则：小说给读者阅读，剧本给剧组拍摄、表演或录制。

## 基本区别

| 对比项 | 小说 | 剧本 |
| --- | --- | --- |
| 目的 | 阅读 | 拍摄、演出、录制 |
| 读者 | 普通读者 | 导演、演员、摄影、美术、声音、剪辑等制作团队 |
| 表达方式 | 文字描写、叙述、心理、作者视角 | 画面、动作、对白、声音、场面调度 |
| 心理描写 | 可以大量描写 | 必须外化，不能直接写不可见内心 |
| 环境描写 | 可以细致、文学化 | 只写拍得到、听得到、会影响表演或镜头的信息 |
| 篇幅单位 | 字数、章节、卷 | 页数、场、时长，约 1 页 ≈ 1 分钟 |

## 转译原则

1. 先找不可拍内容：想起、理解、释怀、无法原谅、害怕、孤独、初恋般的味道、三年前发生了什么、两人聊了很久。
2. 再选择可拍载体：动作、表情、停顿、对白、道具、环境声、字幕、闪回、蒙太奇、新闻/文件/照片、空间调度。
3. 情绪不直接命名，必须让观众从行为和声画中判断。
4. 背景信息不由作者讲述，优先通过角色选择、后果、冲突、物证或逐步透露的对白呈现。
5. 文学比喻只保留可执行画面。例如“阳光像金色河流”可改成“阳光穿过树叶，在地面形成斑驳光影”。
6. 对白必须真的写出来；不能用“两人聊了很久”代替演员要说的话。
7. 时间跨度必须可制作：字幕、转场、蒙太奇、妆发/演员变化、场景变化或具体道具变化。

## 常见转译表

| 小说写法 | 剧本处理 |
| --- | --- |
| 他想起十年前那个夏天 | FLASHBACK，旧照片，声音回放，相关地点/道具触发 |
| 他无法原谅父亲 | 撕毁照片，避开称呼，拒绝接电话，对遗物停顿 |
| 她很害怕 | 呼吸急促，手抖，后退，抓紧门把，压低声音 |
| 风带着初恋般的味道 | 可见风、树叶、衣角、旧歌、人物反应；删掉抽象嗅觉比喻 |
| 三年前发生了很多事 | 字幕、蒙太奇、新闻剪报、伤疤/奖杯/空座位等结果 |
| 两人聊了很久 | 写出有冲突、有信息增量、有潜台词的对白段落 |

## 示例：内心改外化

小说：

```text
林远望着窗外的大雨，忽然想起十年前那个夏天。他一直以为自己已经放下，可直到今天，他才发现自己仍然无法原谅父亲。
```

剧本：

```text
INT. 客厅 - 夜

林远站在窗前。

外面暴雨。

他拿起桌上的旧照片。照片里，少年林远站在父亲身边，两人之间隔着半步。

手机震动。屏幕显示：父亲。

林远看着来电。

他按灭屏幕，把照片反扣在桌上。
```

## 示例：文学描写改画面

小说：

```text
阳光像金色的河流，从树叶间缓缓流淌。风带着初恋般的味道。
```

剧本：

```text
EXT. 校园林荫道 - 上午

阳光穿过树叶，在地面形成斑驳光影。

风吹过，树影晃动。

女孩停在公告栏前。她看见一张泛黄的合照。
```

## 示例：恐惧改可见动作

小说：

```text
张伟很害怕。他觉得整个房间像一个巨大的牢笼，空气越来越稀薄。他不停地回忆童年的经历，希望能够让自己冷静下来。
```

剧本：

```text
INT. 房间 - 夜

张伟呼吸急促。

他不停扯开领口。

汗水顺着额头流下。

墙上的钟声越来越响。

张伟蹲下，双手抱头。
```

## 输出自检

- 场景标头是否包含 INT./EXT.、地点、时间。
- 动作线是否只写看得到、听得到、能表演的内容。
- 情绪是否已通过动作、表情、对白、沉默、道具或声音外化。
- 是否仍有作者解释、心理总结、文学比喻或“聊了很久”这类省略。
- 闪回、字幕、蒙太奇、时间跳跃是否有明确制作方案。
- 对白是否有冲突、潜台词和信息增量。
