# 规则演进

每日更新事实与缺测；每周检查登记的官方资料源；每月复盘容量、误报、漏报与恢复证据。source check 只比较受控下载内容的哈希，变化不代表已确认规则失效。

规则按以下生命周期推进：

1. `rules propose` 生成新版本，原规则保持生效。
2. `rules replay --id <rule-id> --asset <asset>` 对保留的历史样本回放，报告触发差异。
3. `rules shadow --id <rule-id>` 进入至少七天影子观察，不向用户发送候选规则的告警。
4. 至少90%影子采集覆盖率后，由授权操作者运行 `rules activate --id <rule-id>`。
5. 回归时用 `rules rollback` 恢复上一版本；旧评估仍绑定旧规则。

回放触发数量不是准确率。只有具有人确认的故障／误报记录才能评估判断效果。没有足够样本时保持候选，不缩短观察期来制造成功。

代码、采集器和 Skill 升级与规则激活分开。资料变化不授权安装、发布、远程修改或费用。记录结论、证据和可复核的下一步，不记录模型内部推理、私密提示或原始凭据。
