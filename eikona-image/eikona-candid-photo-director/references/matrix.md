# 抓拍写真采样矩阵

机器可读的唯一权威来源是 `scripts/matrix.json`；本文档供人类审阅取值池与语义。修改取值必须先改 `matrix.json`，再同步本文档。

## 固定项（不进矩阵）

- 主体：参数化，默认 `kr-ins-default`（一个极具镜头感的韩国 INS 网红，皮肤白皙，身材夸张）。
- 画幅：默认 9:16 竖幅。
- 模型：`openai/gpt-5.4-image-2`（Eikona 默认图像模型，见根 AGENTS.md 约束）。
- 全局约束：真实生活摄影、极强摄影质感、现代东方夏日写真、画面干净、大块面关系清晰、空间层次明确；前景必须自然侵入画面形成明显遮挡；主色块 ≤ 3—4 个。

## 批内去重

- 组合哈希 combo = sha1(12 维取值) 前 8 位，批内唯一。
- `scene / camera / composition / foreground` 四维批内强制不重复。
- n 上限受此约束：n ≤ min(25, 17, 18, 17) = 17；默认 n=10 安全。
